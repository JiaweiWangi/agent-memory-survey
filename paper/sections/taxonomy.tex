\section{研究脉络与方法分类}

智能体长期记忆系统的研究可按机制演进划分为四个阶段：从奠基性的记忆流与三因子检索，到面向固定上下文窗口的虚拟上下文管理，再到结构化记忆组织，最后走向效率导向的固化与压缩策略。这一脉络并非线性替代，而是问题重心与设计约束的持续迁移。

\subsubsection{记忆流与三因子检索}

Park 等人在 Smallville 沙盒中提出了生成式智能体的奠基范式，以自然语言记忆流记录智能体全部经验，并在检索时综合相关性（recency）、新近性（importance）与重要性三个因子筛选记忆，同时引入反思模块将记忆综合为高层推断\cite{W0001}。作者通过消融实验称观察、规划、反思每个组件都对行为可信度有关键贡献\cite{W0001}。这一工作确立了“写入—检索—综合”的基本框架，但其记忆组织本质上是扁平的相似度检索，且实验环境限于 Smallville 沙盒\cite{W0001}。后续研究者指出，这类基于相似度检索的系统在写入阶段不进行信息蒸馏，读取时完全依赖查询驱动检索，难以处理跨文档矛盾与时间性信息\cite{W0028}。

\subsubsection{上下文工程与虚拟记忆管理}

面对 LLM 固定上下文窗口的限制，MemGPT 将主上下文划分为只读系统指令、可写工作上下文与 FIFO 消息队列，外部上下文类比磁盘存储，仅通过函数调用进行读写\cite{W0002}。作者称记忆编辑与检索完全由 LLM 自主决定，队列驱逐策略可释放约 50\% 上下文窗口空间并生成递归摘要\cite{W0002}。然而，其工作上下文仍为固定大小的非结构化文本块，外部记忆必须显式移入主上下文才能参与推理\cite{W0002}。ExpeL 同样针对上下文窗口限制，通过自主经验收集与自然语言知识提取实现跨任务学习，在推理时召回洞察与过去经验\cite{W0618}。作者明确指出，基于提示的 LLM 智能体受上下文窗口大小限制，无法回忆已见内容\cite{W0618}。这一阶段的共性问题是：记忆仍以非结构化文本为主，检索粒度受限于上下文窗口的物理边界。

\subsubsection{结构化组织：从图到分层与多类型}

为突破基础存储与检索的局限，研究者开始引入图结构与动态组织机制。A-Mem 将新记忆构建为包含上下文描述、关键词、标签等属性的笔记，并在整合新记忆时更新旧记忆的表示，实现记忆演化\cite{W0681}。作者指出，当前系统如 Mem0 只提供基础存储与检索，即使引入图数据库也因固定操作而受限\cite{W0681}。Zep 采用时序知识图谱架构，区分情节子图、语义实体子图与社区子图，并通过双时序模型区分现实有效区间与系统事务区间，使旧边在矛盾时被置为失效但保留在图中\cite{W0684}。作者称在 DMR 基准上 Zep 表现优于 MemGPT（94.8\% vs 93.4\%），在 LongMemEval 上准确率最高提升 18.5\%，延迟降低 90\%\cite{W0684}。

Mem++ 则选择了另一条路径：写入时完整保存带日期与作者的每个文档，不蒸馏、不覆盖；读取时按问题时间上界筛选文档并融合词汇与语义排序\cite{W0028}。作者称这种非破坏性组织在 OrgMemBench 上超越最强基线 8.0–13.1 分，在 gpt-4.1-mini 下比 RAG 高 2.6 分\cite{W0028}。与传统压缩式系统（如 Mem0）覆盖式写入形成对比，Mem++ 保留了冲突陈述的可回答性\cite{W0028}。Synapse 进一步提出扩散激活机制，融合情景与语义记忆以克服“上下文隔离”问题，在 LoCoMo 上加权平均 F1 达 40.5，超过 A-Mem（33.3）、Zep（39.7）与 AriGraph（33.7）\cite{W0099}。HiGMem 则采用分层图记忆与 LLM 引导检索，在 LoCoMo10 上将平均检索轮数从 A-Mem 的 99.84 降至 8.09，对抗性 F1 从 0.54 提升至 0.78\cite{W0030}。

与此同时，MIRIX 提出六种结构化记忆类型（Core、Episodic、Semantic、Procedural、Resource Memory 与 Knowledge Vault），由多智能体框架动态协调更新与检索\cite{W0105}。作者称在 ScreenshotVQA 上相对 RAG 基线准确率提升 35\%、存储降低 99.9\%，在 LOCOMO 上达到 85.4\% SOTA\cite{W0105}。SodaMem 则将证据锚定与时间图结构结合，在检测到同一 subject–predicate 槽位时写入新事实并主动失效旧事实，读取时以软时间窗口加分而非硬过滤\cite{W0222}。作者称在 LongMemEval-S 上 store-of-record 配置达到 92.8\% 准确率（464/500）\cite{W0222}。

\subsubsection{效率与固化策略}

结构化记忆虽然提升了检索质量，却带来了记忆构建的 token 成本问题。RecMem 提出基于复现的记忆固化，作者称在 LoCoMo 基准上记忆构建 token 消耗比基线最多降低 7.8 倍\cite{W0107}。RecMem 论文报告其记忆构建消耗约 193.2K tokens，而 MemoryOS 约 1520.8K、Mem0 约 1459.9K\cite{W0107}。作者称既有系统普遍采用急切记忆固化，RecMem 以差异化组织方式降低固化开销\cite{W0107}。Mem0 本身从生产级视角出发，作者称在 LOCOMO 基准上相比 OpenAI 在 LLM-as-a-Judge 指标上实现 26\% 相对提升，但结合图记忆的整体得分仅比基础版高约 2\%\cite{W0682}，提示图结构在特定评测条件下增益有限\cite{W0682}。

总体而言，早期工作聚焦于“如何记住”，以记忆流和检索因子奠定基础；上下文工程阶段回应“如何突破窗口”，以虚拟上下文和自主编辑缓解物理限制；结构化组织阶段转向“如何组织与演化”，以图结构、分层表示与多类型记忆管理提升信息的可用性，但其增益高度依赖任务与检索设置（见第~4~节与第~5~节）；近期前沿工作则进一步追问“何时该遗忘”与“是否可信”——遗忘治理、来源追踪与错误传播控制成为新的焦点（详见后续章节）。
