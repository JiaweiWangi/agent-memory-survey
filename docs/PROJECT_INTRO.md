# 项目介绍与验收指南

> 写给第一次接触本项目的读者。文中每个关键声明都附有**验证方法**（文件位置或可执行的检查命令），可自行核验，不必信任本文的自述。

---

## 1. 这是什么项目

一门大学学术写作课程的团队作业，要求三人一组：

1. 选一个前沿问题，完成一篇**不少于 30 篇真实文献的综述**（含问题背景、研究脉络、主要挑战）；
2. **设计一个智能体**来完成上述综述（模型与框架不限）；
3. 工作流必须**考虑幻觉问题**，设置**人工验证**节点；
4. 8 分钟汇报（4 分钟讲智能体 + 4 分钟讲研究问题）；
5. 以 **LaTeX** 提交。

本项目的答卷：

- **综述选题**：《大模型智能体的长期记忆：组织、更新与可靠性评测综述》——研究 LLM 智能体如何跨会话保存、组织、更新记忆，以及这些记忆何时会出错。选题聚焦"**更新**"与"**可靠性**"两个维度，避免写成面面俱到的泛综述。
- **智能体**：一个 Python 实现的文献综述智能体（约 3000 行），它真实完成了本项目从检索、筛选、深读、证据提取到草稿生成的全部可自动化环节——本文综述本身就是它的运行产物。

## 3. 研究内容速览

### 3.1 研究问题（五问，冻结于 docs/protocol.md）

1. **RQ1 定义与边界**：长期记忆与上下文历史、静态 RAG、参数知识有什么区别？
2. **RQ2 组织与使用**：写入、组织、检索方法如何影响可用性与成本？
3. **RQ3 更新与遗忘**：信息变化、冲突、过时记忆如何处理？
4. **RQ4 可靠性**：错误如何进入记忆并影响后续决策？如何发现与控制？
5. **RQ5 评测**：基准是否真正考察跨会话记忆与更新能力？

### 3.2 文献是怎么选出来的（筛选漏斗，全部真实数字）

```
104 次检索运行（OpenAlex/Crossref/arXiv，含 17 次失败如实入档）
  → 691 项独立研究（DOI/arXiv ID/题名三重键去重，多版本归并）
    → 255 项通过题名摘要初筛（42 排除带理由码，10 待定）
      → 40 篇核心阅读池（七层结构，每篇回答"解决什么/承担什么/有何不同"三问）
        → 39 篇完成正文深读（5 页/篇，139 条核心池证据）
          → 39 项进入正文实际引用
```

核心池七层（避免主题失衡，尤其防止综述变成"记忆投毒论文集"）：基础系统 8 / 组织检索 7 / 更新遗忘 7 / 评测 7 / **非恶意可靠性 5** / 安全投毒 3 / 综述边界 3。

### 3.3 四个代表性发现（每个都可回查原文页码）

1. **结构化组织并非必然更好**：图结构记忆在 LongMemEval 上 token F1 0.417，反而低于匹配预算的扁平向量基线 0.468（W0034，pdf:p1）；
2. **遗忘便宜但非免费**：一次图剪枝移除 9.8% 节点/9.5% 存储而 F1 变化不显著（CI 含 0），但 judged correctness 降 1.6 点（W0034）；
3. **检索到 ≠ 用得上**：代理仅 55% 的时间对正确检索值采取行动，忽略率 0.45–0.53（W0031）；
4. **错误会滚雪球**：多阶段流水线中幻觉检测率从 72.0% 沿链单调降至 50.9%；边界处设防比末端检查有效得多（W0688）。

完整论断映射表（20 项核心论断 → 文献 → 原文页码 → 摘录 → 适用条件）：`data/derived/claims_map.md`。

## 4. 智能体是怎么工作的

### 4.1 架构（两层形态）

```
研究目标 / 当前状态
      ↓
协调 Agent（coordinator.py）：观察 RQ 覆盖缺口 → 选择工具 → 执行 → 记录
      ↓
工具层（确定性）：检索（OpenAlex/Crossref/arXiv）· 去重（三重键）·
  PDF 页级提取 · 证据/陈述/记忆事件溯源 · 引用检查 · 身份核验
      ↓
持久化（data/*.jsonl，全部追加式，可重启恢复）
      ↓
带引用草稿 + 缺口清单 + 人工核验包
```

- **协调器回合**（G2 演示）：模型在工具循环中自主决策。两次真实决策记录在案：观察到 RQ1/RQ5 证据缺口后**自选 7 个补检检索词**；工具链缺证据枚举能力时**拒绝编造 ID 并报告缺口**（后按其建议补了工具）。
- **批处理管线**（G3 规模化）：40 篇深读用逐篇单次模型调用，与协调器共用同一套摘录验证器。

### 4.2 反幻觉机制（本项目的设计核心）

模型提交证据摘录时，系统做**逐字签名验证**：摘录剔除空白与连字符（排版产物）后的字符序列，必须是所指 PDF 页提取文本的**连续子串**。改写、缩写、省略号压缩、凭记忆复述、表格单元格拼接全部被拒，并返回页面上最相似的原文片段供模型自纠错。

**实战数据**（`runs/` 运行日志可复核）：拦截 258 次（协调器）+ 102 次（批处理）= 360 次；独立抽查 4 条证据回查原 PDF 页，4/4 逐字存在。

相关防线（历轮外部审查后加的）：
- **身份核验**：PDF 首页必须与记录题名匹配（首显著词必须命中），防止"下载错论文还提取证据"——这曾真实发生并被修复（见 §6）；
- **废止机制**：判为错配的证据经 reviews.jsonl 追加废止记录，原始记录保留供审计，但所有生产路径（证据列表/RQ 统计/论断提交）自动排除；
- **引用检查**：草稿中每个 `\cite` 必须指向核心池中有证据的研究。

### 4.3 评估（诚实的部分）

12 个冻结案例 × 3 条件（A 无记忆 / B 上下文注入 / C 结构化记忆），其中跨运行案例为**真实两阶段实验**（阶段 1 写入持久化 → 新实例 → 阶段 2 恢复）。

**最终结果（三态口径：成功/失败/待核验）**：

| 条件 | 成功 | 失败 | 待核验 |
|---|---|---|---|
| A 无记忆 | 2/12 | 10/12 | 0 |
| B 上下文注入 | **11/12** | 0 | 1 |
| C 结构化记忆 | 9/12 | 3/12 | 0 |

如实说明：**B（朴素上下文注入）在小记忆库场景最好**；C（结构化记忆）的价值在于真实跨运行持久化（两阶段实验直接验证）和支撑本项目 342 条证据的实际研究流程，而非评测分数。M4-03 开放式内容主张超出自动判分可靠边界，全部转人工核验，不默认成功。

判分方法与原始输出全部公开：`evaluation/report.md`（v6）、`evaluation/results.jsonl`。

## 6. 如何验收（建议流程）

**第一步：环境与测试（5 分钟）**

```bash
cd Acdamic-Writing-Class-Task
uv sync                      # 恢复依赖
uv run pytest                # 期望：31 passed
```

**第二步：核对硬指标（5 分钟）**

```bash
# 正文实际引用数（应输出 39）
uv run python -c "
import re
from pathlib import Path
text = ''.join(f.read_text(encoding='utf-8') for f in Path('paper/sections').glob('*.tex'))
print(len({w for g in re.findall(r'\\\\cite\{([^}]+)\}', text) for w in g.split(',')}))"

# 语料完整性（有效证据 342 / 废止 7 条保留 / 检索 104 次）
uv run litreview check --scope corpus

# 核心池论文身份核验（39/40 通过；W0056 无 PDF 为已知限制）
uv run litreview check --scope identity
```

**第三步：抽查证据真实性（10 分钟，最重要）**

```bash
# 打开 data/derived/claims_map.md，随机挑 2-3 项论断
# 每项都标了 work_id + 原文定位（如 "pdf:p1 Abstract"）
# 对照 sources/ 下同名 PDF 翻到该页，核对摘录是否逐字存在
```

例如论断 1（图记忆 F1 0.417 vs 0.468）→ W0034 → `sources/2608.28978.pdf` 第 1 页摘要。

**第四步：看三份 PDF**

`paper/main.pdf`（重点：第 5 页筛选漏斗图、第 8 页谱系表、第 6–8 页方法表、第 10–14 页更新与可靠性章节）；`agent_report/main.pdf`（架构与评估）；`slides/main.pdf` + 讲稿。

**第五步：从提交包独立复查（可选，证明不依赖原目录）**

```bash
cd submission/agent_source
uv run litreview --data-dir ../evidence_manifest check --scope corpus
# 期望读出包内数据：726 条记录 / 有效证据 342 / 检索 104 次
```

**第六步：审阅诚实的失败与修复记录**

`docs/decisions.md`（14 条决策记录 D-1~D-14）、`docs/final_acceptance.md`（五轮外部审查逐项核验表，含每轮确认/不成立的判断与依据）。这个项目被外部审查抓到过真实的严重错误——论文身份错配（气候论文的证据混入 MemoryBank）、评估误判（把"查无记录"计为成功）、判分放行编造内容——每次都修复并加了回归测试。这些记录没有删除，是验收时值得看的部分。

## 8. 一分钟版本

> 三人课程作业：用自己写的文献综述智能体，产出一篇 22 页、39 项真实引用的《大模型智能体长期记忆综述》。智能体的核心是"逐字证据验证"——模型抄错一个连字符都会被拒，360 次拦截零漏网；错误一旦发现（含两轮外部审查抓出的论文错配与评估误判）均以废止记录 + 回归测试方式修复，全程日志可追溯。研究本身发现：结构化记忆组织并不必然优于扁平存储、遗忘便宜但有代价、检索到不等于用得上、错误沿流水线滚雪球。剩人工核验、署名与排练。
