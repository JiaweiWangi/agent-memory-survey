# 8 分钟讲稿（G6 草稿；时长需真人排练校准）

## 第一部分：智能体（4 分钟，页 1–4）

**页 1（0:30）** 作业要求综述+智能体。我们的底线设计是：每条引用可回查、每步可审计。反幻觉验证器实战拦截了 360 次模型改写，零条被拒摘录进入证据库。

**页 2（1:00）** 架构两层：协调 Agent 在工具循环里自主决策——观察 RQ 缺口、选工具、执行、记录；批处理管线负责 40 篇深读的规模化。全部状态是追加式 JSONL，重启可恢复，记忆有 valid/trust 双状态。

**页 3（1:20）** 演示核心机制：摘录提交时的字符签名验证——模型抄错一个连字符都会被拒，系统返回最相似原文让它自纠。两次真实自主决策：一次缺口驱动补检（自选检索词），一次拒绝编造证据 ID 并报告工具缺口。

**页 4（0:50）** 评估：12 个冻结案例 × 3 条件。C（结构化记忆）编造最少、跨会话/跨运行全过。诚实说明混杂因素：C 用了工具循环，优势不能全归因记忆机制；小样本不构成统计证据。人工核验包已生成，40 项文献核验待成员完成。

## 第二部分：研究问题与进展（4 分钟，页 5–8）

**页 5（0:40）** 先划边界：长上下文、静态 RAG、参数知识都不等于长期记忆——判据是有没有跨会话的显式读写闭环。五个 RQ 从定义边界到评测公平性。

**页 6（1:20）** 脉络三代：2023 奠基期解决"存得下"（记忆流、上下文分页、语言化经验）；2024–25 组织化（图结构、时间知识、显式记忆操作）；2026 前沿转向"信得过"（遗忘治理、provenance、效率）。

**页 7（1:10）** 四个带数字的发现：遗忘便宜且有效但图优于向量被证伪；检索到不等于用得上（55% 行动率）；错误会滚雪球（独立于攻击）；安全有代价。

**页 8（0:30）** 缺口：现有基准大多没考察更新正确性。结论一句话：这个领域正在从"存得下"转向"信得过"。

## 答辩准备（EXECUTION_PLAN §9）

- 长期记忆与长上下文/RAG 边界 → 页 5 判据
- 某篇为何纳入/排除 → 筛选理由码 + 核心池三问（docs/decisions.md D-3）
- 智能体哪一步做了决策 → 页 3 两次真实案例（runs/ 日志）
- 如何证明陈述被论文支持 → 逐字验证 + 定位回查（evidence.jsonl）
- 哪些是真人做的 → 筛选策略制定、边界裁决、核验（进行中）、讲稿排练
- 评估为何不能证明普遍更优 → 混杂因素 + 小样本（agent_report §6）
